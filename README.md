# ☕ Coffee Shop Sales Dashboard (Excel Project)

## 📊 Overview
<img width="1064" height="510" alt="image" src="https://github.com/user-attachments/assets/6f0fd0b8-1715-46cd-ae67-0b4503432562" />

This project is an interactive **Excel dashboard** built to analyze coffee shop sales performance.
It provides insights into sales, customer behavior, product performance, and store-level trends.

---

## 🎯 Objectives

* Track total sales and customer footfall
* Analyze product category performance
* Understand customer ordering patterns
* Identify peak sales hours and busy days
* Compare performance across store locations

---

## 📌 Key Metrics

* **Total Sales:** $698,812.33
* **Total Footfall:** 149,116
* **Average Bill per Person:** 4.69
* **Average Orders per Person:** 1.44

---

## 📈 Dashboard Features

### 1. Sales & Footfall Analysis

* Total sales and customer visits overview
* Store-wise comparison (Astoria, Hell’s Kitchen, Lower Manhattan)

### 2. Time-Based Insights

* Quantity ordered by hour
* Weekday order trends

### 3. Product Insights

* Top 5 products based on sales
* Category-wise sales distribution

### 4. Customer Behavior

* Order size distribution (Large, Regular, Small)
* Average spending patterns

### 5. Interactive Filters (Slicers)

* Month-wise filtering
* Day-wise filtering
